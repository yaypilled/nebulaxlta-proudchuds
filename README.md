# NebulaX LTA 2026 — PS3 Rail Corrugation

Rail corrugation model. Classifies a 1-second axle-box vibration recording as
`Normal`, `Side I`, or `Side II`.

**Scope:** rail corrugation only. Door, ACV and SHM are not implemented.

## For the app: the only thing you need

```python
from pathlib import Path
from src.rail.predict import predict

df = predict(Path("some/folder/of/csvs"))   # or a single .csv file
df.to_csv("rail_predictions.csv", index=False)
```

`predict()` returns a `pandas.DataFrame` **already in submission schema** —
columns exactly `file_id,prediction`, one row per input file, in natural
numeric order. No renaming, reordering or casting needed.

- **Accepts** a directory of `.csv` files, or a single `.csv` path.
- **Returns** `file_id` (filename including `.csv`) and `prediction`
  (`Normal` / `Side I` / `Side II`).
- **Self-contained.** All preprocessing is inside the function. It loads the
  trained model itself from `artifacts/rail/model.joblib`.
- **Does NOT need the 6 GB dataset or the `NEBULAX_DATA` env var.** Those are
  only for retraining.

Equivalent CLI, if you'd rather shell out:

```
python -m src.rail.predict --input <path> --output rail_predictions.csv
```

The CLI is a logic-free wrapper over the same `predict()` — it parses two
arguments, calls the function, writes the CSV. Nothing else. So the app and
the CLI cannot drift apart.

## Setup

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Python 3.13. Everything installs as wheels; no build tools needed.

Verify it works:

```
.venv\Scripts\python.exe -m pytest                      # 7 tests, all should pass
.venv\Scripts\python.exe -m src.rail.predict --input <test_csv_dir> --output rail_predictions.csv
.venv\Scripts\python.exe scripts/validate_submission.py rail_predictions.csv
```

`validate_submission.py` checks the filename, header, label values, empty rows
and the 68-row count. It exits non-zero on any violation. Use
`--expect-rows N` if the held-out set is not 68 files.

## Things the app should surface

**`predict()` prints two counters to stdout. Both belong in the UI.**

- `low_speed_rule_fired: N` — files below 1.28 m/s where no wheel-rail rolling
  interaction exists, so corrugation is physically undetectable. These are
  predicted `Normal` by an explicit stated rule, **not by the model**. On the
  development test set this fired on **10 of 68 files**, so roughly one row in
  seven. It is honest to show this rather than hide it.
- `fallbacks: N` — files where something went wrong and a default was emitted.
  Was 0 on the development set. **If this is ever non-zero, investigate; do not
  ship silently.**

## Result

Restricted macro F1 **0.7765** (std 0.0833, p10 0.6483) over 50 folds of
`RepeatedStratifiedKFold(5x10, seed 20260918)`. Full-set 0.7858.

The **restricted** figure (files at or above 9.70 m/s) is the headline: train
speed correlates with the label, so below that cut a model can score by
learning "fast = fault" rather than anything about corrugation. Above it that
shortcut is unavailable by construction. Quote the restricted number.

Baselines it beats, all fitted in-fold: always-Normal 0.2798, a physics rule
0.5381, and speed-only 0.3078.

**Zero leaderboard uploads have been used.** All five remain.

## Before the write-up

Read `docs/backlog.md`. Known limitations, briefly: two byte-identical
duplicate file pairs in Train (so 226 distinct recordings, not 228); Side I
rests on only 14 files; and Train and Test have near-identical speed
composition, so the confound likely persists into the held-out set — which is
the reason the restricted number is the one to quote.

## Note on the held-out test files

The `Test1.csv`–`Test68.csv` in the dataset are for development. Per spec
§2.3 the organisers distribute the real held-out test **inputs** before the
deadline. Re-run `predict()` on those when they arrive — the committed model
needs no retraining.

Per spec §4.1 item 2, the submitted `predictions.zip` must be generated by
running those files **through the app**, and the demo video is the evidence
that happened.
